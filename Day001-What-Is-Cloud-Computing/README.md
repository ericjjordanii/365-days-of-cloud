## Objective
Define cloud computing, explain the problem it solves, and connect it to a practical cloud scenario.

## What Is It?
Cloud computing is the delivery and consumption of computing resources over the internet instead of requiring an organization to own and maintain all of the underlying physical infrastructure itself.

## Simple Explanation
A useful analogy is renting an apartment instead of building a temporary place to live from raw materials. The property still physically exists, but another organization owns and maintains it while you consume what you need under an agreed usage model.

## Why It Matters
Cloud computing reduces the need to purchase infrastructure far in advance of demand. It also makes it easier to increase or decrease resources as needs change instead of committing to fixed capacity before actual usage is known.

## Key Concepts
- Cloud resources still run on physical infrastructure.
- Cloud providers own and operate the underlying data centers and hardware.
- Customers consume services and capacity rather than building every layer themselves.
- Cloud can reduce large upfront infrastructure commitments.
- Resources can be scaled as demand changes.
- Cloud computing is broader than online file storage.

## Real-World Example
A startup expecting anywhere from 500 to 500,000 users could avoid purchasing enough physical infrastructure for the largest possible outcome on day one. If growth is smaller than expected, it avoids unnecessary upfront spending. If demand grows quickly, additional cloud resources can be provisioned without building a new data center first.

## Azure / Cloud Example
In Microsoft Azure, an organization can consume services such as virtual machines, storage, managed databases, and virtual networking while Microsoft operates the physical data-center infrastructure beneath those services.

## What I Learned
Cloud computing changes how infrastructure is consumed. The physical servers, storage, networking equipment, power, cooling, and facilities do not disappear. The cloud provider operates those physical layers while customers consume configurable resources and services over a network.

## What Confused Me
The word "cloud" can make the infrastructure sound invisible or purely virtual even though every cloud service ultimately depends on physical systems somewhere.

## What Finally Clicked
The apartment analogy made the model easier to understand: using cloud infrastructure is closer to renting access to an existing resource than building and maintaining the entire underlying environment yourself.
